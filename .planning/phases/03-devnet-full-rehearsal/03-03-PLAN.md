<objective>
Upload the logo derivatives + off-chain metadata JSON to Arweave (primary, permanent storage) and record the URLs so Plan 03-04 (Rehearsal 1) and Plan 03-05 (Rehearsal 2) can pass the Arweave URL as the on-chain `uri` field in the TokenMetadata extension. GitHub raw URLs serve as an out-of-band verifiable mirror.

Purpose: The on-chain `uri` field in TokenMetadata is immutable-in-practice (any update costs a multisig proposal). Pointing it at Arweave means wallets/explorers can fetch the JSON forever without the CAYC team maintaining any CDN. This plan is a prerequisite for both rehearsals — without real Arweave URLs, Rehearsal 2's wallet-rendering verification would show broken images.

Output:
- Arweave TX IDs for 2 logos (512 + 1024) and 2 JSON files (rehearsal-1 + rehearsal-2)
- artifacts/metadata-hosting.json (source of truth mirror)
- Updated assets/metadata/rehearsal-*.json with real image URLs (not placeholders)
- docs/runbooks/metadata-hosting.md

**Contains a checkpoint** because Arweave uploads require a funded wallet (SOL-denominated via Turbo SDK, or SOL via Irys). The checkpoint pauses so the user can either (a) fund the upload wallet from their own account or (b) approve a treasury-held devnet wallet for the spend. Devnet rehearsal uploads use ~$0.10 USD equivalent — trivial, but should not be charged silently.
</objective>

    Create `scripts/assets/upload-metadata.ts`:
    - Takes `--rehearsal <1|2>` arg (required) so uploads are per-rehearsal and incremental
    - Takes `--force` to re-upload even if artifacts/metadata-hosting.json already has that rehearsal's entry
    - Loads devnet proposer keypair from `keys/devnet/proposer.json`
    - Uploads `assets/logo-512.png`, `assets/logo-1024.png` first (images), then updates the corresponding JSON file's `image` field to reference the 512 Arweave URL, then uploads the updated JSON
    - Writes/merges entry into artifacts/metadata-hosting.json ({...prior, [rehearsal_N]: {...new}})
    - Emits log lines: `Uploading logo-512.png → tx <id>`, `Uploading logo-1024.png → tx <id>`, `Updating rehearsal-N.json image field`, `Uploading rehearsal-N.json → tx <id>`
    - Idempotence: if artifact already has entry and no --force, skip with "rehearsal_N already uploaded at <date>" message and exit 0

    Skeleton:
    ```typescript
    #!/usr/bin/env -S tsx
    import { Command } from 'commander';
    import { Keypair } from '@solana/web3.js';
    import { readFileSync, writeFileSync, createReadStream, statSync, existsSync } from 'node:fs';
    import { resolve } from 'node:path';
    import { TurboFactory } from '@ardrive/turbo-sdk';
    import bs58 from 'bs58';
    import { loadEnv } from '../../src/env/load.js';

    loadEnv('devnet');  // devnet-scoped; safe

    const program = new Command();
    program
      .requiredOption('--rehearsal <n>', '1 or 2')
      .option('--force', 'overwrite existing entry')
      .parse(process.argv);
    const opts = program.opts();
    const rehearsal = Number(opts.rehearsal) as 1 | 2;
    if (rehearsal !== 1 && rehearsal !== 2) throw new Error('--rehearsal must be 1 or 2');

    const HOSTING_ARTIFACT = resolve('artifacts/metadata-hosting.json');
    const JSON_FILE = resolve(`assets/metadata/rehearsal-${rehearsal}.json`);
    const KEY = `rehearsal_${rehearsal}` as const;

    // Idempotence
    let artifact: Record<string, unknown> = { generated_at: new Date().toISOString() };
    if (existsSync(HOSTING_ARTIFACT)) {
      artifact = JSON.parse(readFileSync(HOSTING_ARTIFACT, 'utf8'));
      if ((artifact as any)[KEY] && !opts.force) {
        console.log(`${KEY} already uploaded. Pass --force to re-upload.`);
        process.exit(0);
      }
    }

    // Load devnet proposer keypair
    const kpBytes = JSON.parse(readFileSync('keys/devnet/proposer.json', 'utf8')) as number[];
    const keypair = Keypair.fromSecretKey(new Uint8Array(kpBytes));

    // Authenticate Turbo with SOL
    const turbo = TurboFactory.authenticated({
      privateKey: bs58.encode(keypair.secretKey),  // Turbo accepts base58-encoded SOL secret
      token: 'solana',
    });

    // Check Turbo Credits balance; top up if needed
    const balance = await turbo.getBalance();
    // ~5 KB logo + ~5 KB logo + ~1 KB JSON = ~11 KB → free tier on Turbo if small enough,
    // otherwise ~0.001 SOL per upload. Budget 0.01 SOL for safety.
    if (balance.winc === '0') {
      await turbo.topUpWithTokens({ tokenAmount: 10_000_000n });  // 0.01 SOL in lamports
      console.log('Topped up Turbo with 0.01 SOL worth of credits');
    }

    // Upload logo-512.png
    const logo512Result = await turbo.uploadFile({
      fileStreamFactory: () => createReadStream('assets/logo-512.png'),
      fileSizeFactory: () => statSync('assets/logo-512.png').size,
      dataItemOpts: { tags: [{ name: 'Content-Type', value: 'image/png' }] },
    });
    const logo512Url = `https://arweave.net/${logo512Result.id}`;
    console.log(`logo-512 → ${logo512Url}`);

    // Upload logo-1024.png
    const logo1024Result = await turbo.uploadFile({
      fileStreamFactory: () => createReadStream('assets/logo-1024.png'),
      fileSizeFactory: () => statSync('assets/logo-1024.png').size,
      dataItemOpts: { tags: [{ name: 'Content-Type', value: 'image/png' }] },
    });
    const logo1024Url = `https://arweave.net/${logo1024Result.id}`;
    console.log(`logo-1024 → ${logo1024Url}`);

    // Update JSON's image field to point at 512 URL (primary display size)
    const json = JSON.parse(readFileSync(JSON_FILE, 'utf8'));
    json.image = logo512Url;
    writeFileSync(JSON_FILE, JSON.stringify(json, null, 2) + '\n');
    console.log(`Rewrote ${JSON_FILE} image → ${logo512Url}`);

    // Upload the updated JSON
    const jsonResult = await turbo.uploadFile({
      fileStreamFactory: () => createReadStream(JSON_FILE),
      fileSizeFactory: () => statSync(JSON_FILE).size,
      dataItemOpts: { tags: [{ name: 'Content-Type', value: 'application/json' }] },
    });
    const jsonUrl = `https://arweave.net/${jsonResult.id}`;
    console.log(`rehearsal-${rehearsal}.json → ${jsonUrl}`);

    // Determine GitHub raw URL (assumes `origin` remote points to github.com/<owner>/<repo>)
    const remote = execFileSync('git', ['remote', 'get-url', 'origin'], { encoding: 'utf8' }).trim();
    const match = remote.match(/github\.com[:/]([^/]+)\/([^/\.]+)/);
    const githubRawUrl = match
      ? `https://raw.githubusercontent.com/${match[1]}/${match[2]}/main/assets/metadata/rehearsal-${rehearsal}.json`
      : null;

    (artifact as any)[KEY] = {
      logo_512_arweave_tx: logo512Result.id,
      logo_512_arweave_url: logo512Url,
      logo_1024_arweave_tx: logo1024Result.id,
      logo_1024_arweave_url: logo1024Url,
      json_arweave_tx: jsonResult.id,
      json_arweave_url: jsonUrl,
      github_raw_url: githubRawUrl,
      uploaded_via: '@ardrive/turbo-sdk',
      uploaded_at: new Date().toISOString(),
    };
    writeFileSync(HOSTING_ARTIFACT, JSON.stringify(artifact, null, 2) + '\n');
    console.log(`Wrote ${HOSTING_ARTIFACT}`);
    ```
