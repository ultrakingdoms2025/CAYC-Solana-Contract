**`.gitleaks.toml`** — custom gitleaks config that adds Solana-specific rules to the default ruleset:

```toml
# Gitleaks config for CAYC repo.
# Extends gitleaks' built-in defaults and adds Solana-specific detections.

title = "CAYC gitleaks config"

[extend]
useDefault = true

# -- Solana keypair JSON files (array-of-64-uint8, the format `solana-keygen` writes) --
[[rules]]
id = "solana-keypair-array"
description = "Solana keypair exported as a JSON array of 64 bytes"
# Matches e.g. [123,45,67,89,... (64 numbers)]
regex = '''\[\s*(?:[0-9]{1,3}\s*,\s*){63}[0-9]{1,3}\s*\]'''
tags = ["solana", "keypair", "secret"]

[[rules.allowlist]]
description = "Example/template files are permitted"
paths = [
  '''\.env\.example$''',
  '''\.env\..+\.example$''',
]

# -- Solana keypair mnemonic hint (24-word BIP39 in a file) --
[[rules]]
id = "solana-mnemonic-24-word"
description = "BIP39 24-word mnemonic phrase (heuristic)"
regex = '''(?i)\b((?:[a-z]{3,10}\s+){23}[a-z]{3,10})\b'''
tags = ["solana", "mnemonic", "secret"]

# -- Helius RPC URLs with real API keys (our format specifically) --
[[rules]]
id = "helius-rpc-api-key"
description = "Helius RPC URL with embedded api-key"
regex = '''https://(?:devnet|mainnet)\.helius-rpc\.com/\?api-key=[0-9a-f]{8,}'''
tags = ["helius", "rpc", "secret"]

[[rules.allowlist]]
description = "Placeholder in env examples is OK"
regexes = [
  '''REPLACE_WITH_(DEVNET|MAINNET)_KEY''',
]
```

**`.husky/pre-commit`** (the actual hook — runs gitleaks on staged changes):

```sh
#!/usr/bin/env sh

# CAYC pre-commit hook.
# 1. Run gitleaks on staged changes (blocks commit if secrets found).
# 2. Run prettier --check on staged .ts/.md/.json files (non-blocking nudge).
# 3. Run tsc --noEmit (blocks commit if TypeScript fails to compile).

set -e

# --- Step 1: gitleaks (BLOCKING) ---
if ! command -v gitleaks >/dev/null 2>&1; then
  echo "ERROR: gitleaks not installed. Install per README (brew install gitleaks / scoop install gitleaks) and retry."
  echo "       Commit aborted — do not bypass without explicit authorization."
  exit 1
fi

echo "[pre-commit] Running gitleaks on staged changes..."
gitleaks protect --staged --config .gitleaks.toml --redact --verbose || {
  echo ""
  echo "ERROR: gitleaks detected potential secrets in staged changes."
  echo "       Review the findings above. Do NOT bypass with --no-verify."
  echo "       If this is a false positive, update the allowlist in .gitleaks.toml."
  exit 1
}

# --- Step 2: prettier check (non-blocking on unformatted MD, blocking on .ts/.json) ---
STAGED_TS_JSON=$(git diff --cached --name-only --diff-filter=ACM | grep -E '\.(ts|json)$' || true)
if [ -n "$STAGED_TS_JSON" ]; then
  echo "[pre-commit] Checking formatting on staged .ts/.json files..."
  echo "$STAGED_TS_JSON" | xargs -r npx prettier --check || {
    echo "ERROR: Formatting check failed. Run 'pnpm format' and re-stage."
    exit 1
  }
fi

# --- Step 3: typecheck (BLOCKING; skipped if no .ts changes staged, as tsc on empty tree is wasted work) ---
STAGED_TS=$(git diff --cached --name-only --diff-filter=ACM | grep -E '\.ts$' || true)
if [ -n "$STAGED_TS" ]; then
  echo "[pre-commit] Running tsc --noEmit..."
  pnpm typecheck || {
    echo "ERROR: TypeScript failed to compile. Fix errors before committing."
    exit 1
  }
fi

echo "[pre-commit] OK"
```
