**Query methodology (run each of the four, in this order; copy raw output into the report):**

1. **Jupiter verified token list** — the canonical authoritative source for Solana verified tokens:
   - Primary API query: `curl -s 'https://lite-api.jup.ag/tokens/v1/tagged/verified' | jq '[.[] | select(.symbol == "CAYC" or (.name | ascii_downcase | contains("cayc")))]'`
   - Fallback if endpoint has changed: `WebFetch` on `https://verified.jup.ag/` with prompt "List any tokens with symbol CAYC or name containing 'cayc' or 'cyber ape yacht'."
   - Also query the full (unverified) Jupiter tradable token search: `curl -s 'https://tokens.jup.ag/tokens?tags=community' | jq '[.[] | select(.symbol == "CAYC")]'` — unverified mints that squat the symbol still count as conflicts for listing submissions.
   - Record: number of matching tokens, mint address(es) of any matches, verified status of any matches.

2. **Solscan token search**:
   - Primary: `WebFetch` on `https://solscan.io/search?keyword=CAYC` with prompt "List every token whose symbol is exactly CAYC, including mint address and whether the token is verified. Return JSON."
   - Secondary (direct Solscan public API — may require API key; if it fails, note the failure and fall back to the UI result): `curl -s 'https://public-api.solscan.io/token/list?symbol=CAYC&limit=10'`
   - Record: number of matching tokens, mint address(es) of any matches, any "verified" badge information.

3. **CoinGecko coin search**:
   - Primary: `curl -s 'https://api.coingecko.com/api/v3/search?query=CAYC' | jq '.coins[] | {id, name, symbol, market_cap_rank, platforms}'`
   - Filter the JSON output for: any coin where `symbol == "CAYC"` (case-insensitive) OR `name` contains "cyber ape yacht".
   - Record: matching coins (id, name, symbol, rank), and whether any are on Solana (platforms.solana).

4. **CoinMarketCap search**:
   - Primary: `WebFetch` on `https://coinmarketcap.com/currencies/?q=CAYC` with prompt "List every cryptocurrency whose symbol is CAYC or whose name contains 'cyber ape yacht'. Include the CMC slug/URL, symbol, and the chain if displayed."
   - Secondary (if the public quote endpoint is accessible): `curl -s 'https://pro-api.coinmarketcap.com/v1/cryptocurrency/map?symbol=CAYC'` — this requires an API key, so if we have none, note that and rely on the WebFetch result.
   - Record: matching listings, slug URLs, and chain (Solana vs other).
